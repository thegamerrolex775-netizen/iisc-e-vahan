HOW THE ALGORITHM THINKS

It compares walking + e-Vahan combinations

It checks direct rides and one-transfer rides, scores each by walking time + estimated e-Vahan time + waiting/transfer penalties, then chooses the lowest total.

Routing model

Fastest-route mode checks direct e-Vahan rides and one-transfer journeys. Walking legs use OpenStreetMap-based pedestrian routing when available.

Coordinate model

Campus e-Vahan stop anchors are bundled locally so the app does not need to geocode 25 stops before it can route. They can later be replaced with verified coordinates.

Free-service note

OpenStreetMap tiles and public routing services are community infrastructure. Use them normally and do not bulk-download tiles or send automated high-volume requests.
